# Cut-out Editorial Moodboard

One-page cover-direction prototype for the Playful Scrapbook Social system.

This is intentionally a **catalogue-collage** direction: transparent lifestyle objects frame a clear editorial headline on a coloured paper background. It is not part of the photo-first Reading Nook system and should remain a separate variant if it becomes a sellable carousel pack.

## Design contract

- Canvas: 1080 x 1350 px (4:5)
- Base: periwinkle paper `#90A7D8` with a very subtle grain layer
- Type: high-contrast serif in warm white; the oversized italic word is the visual hook
- Objects: 3 large, 4 medium, and 4 small transparent assets; use existing core stickers only
- Keep the left-centre headline pocket clear and independently editable
- All objects remain independent layers when rebuilt in Canva

## Build

Open `index.html` locally, or run:

```powershell
node .\render.mjs
```

The rendered proof is written to `output/moodboard-cover.png`.
