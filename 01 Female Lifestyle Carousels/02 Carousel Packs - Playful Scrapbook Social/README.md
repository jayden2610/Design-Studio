# Playful Scrapbook Social Carousel Pack

This pack follows the Playful Scrapbook Social contract and its five approved layout patterns.

## Image-first rule

The photo is part of the design surface. Always inspect the actual crop before finalising text, stickers, tape, or cards.

- Use cocoa ink on pale areas and cream / white type only on dark areas.
- If the photo is busy or changes tone behind the copy, use one soft translucent wash, paper strip, sticker card, or local gradient.
- Keep faces, hands, and story objects unobstructed.
- Text support must stay editable and should not become a heavy opaque panel.
- Test every slide at mobile-preview size. If the type is not immediately readable, move it or change the crop.
- For type directly on light or mid-tone photography, use deep berry `#9B3E4B` for headlines, butter `#E6BC61` for small tabs, and cocoa `#733F38` for supporting labels; add a subtle cream offset shadow only if required.

## Sticker rule

Use a deliberate 2–5 piece sticker cluster that supports the main photo and copy. Keep those stickers inside the composition and away from faces, hands, and key objects; avoid scattering one decoration into every empty corner.
