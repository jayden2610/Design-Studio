## Non-negotiable: text placement rule

**Text is never a solid card, block, or scrim covering the subject.** The reference pack Jayden pulled from (`Carousel Pictures/photo_1...jpg`) proves the technique: words like "Spend / a / selfcare / day / in my life" are broken apart and each one dropped into its own separate negative-space pocket around the person — wall gaps, sky, the space between an arm and a shelf, floor-level gaps. The person is fully visible at all times. No word ever crosses her body or hides her.

**How to apply this per photo:**
1. Look at the actual photo first. Identify 3-5 real empty pockets (not assumed ones) — e.g. a plain wall strip, a window/sky area, a gap made by a limb or prop against furniture, floor space.
2. Break the headline into individual words or short fragments. Assign each fragment to ONE pocket, sized to fit that pocket.
3. Per-pocket, choose ink color for contrast against what's actually behind it — dark ink on a clean light wall, light ink + soft `text-shadow` (never an opaque background) on a busier or mid-tone area. Never solve contrast by boxing the text — solve it by re-coloring/re-positioning per pocket.
4. Small stickers (page-number tab, location pin, squiggle underline) follow the same rule: each one sits in its own genuinely empty pocket, never stacked on the subject, and each one does a distinct job (numbering, labeling, accenting) — no sticker "just because it looks nice."
5. Sanity check before showing a preview: does the subject's full pose/face-area/hands remain visible and unobstructed? If any fragment crosses her, move it or shrink it until it doesn't.

This corrects an earlier mistake in this project: an initial cover draft used a solid cream card behind all the text, which fully hid the person in the photo. That approach is wrong for this style — do not repeat it.

## Style system (Set 4 + Set 5, locked together)

- **Type pairing:** Quicksand Bold (headline fragments, lowercase) + DM Sans Medium tracked-caps (caption) + DM Sans Regular (sub line).
- **Palette:** sampled per-photo, not a fixed brand hex. Pull 2-3 dominant tones from each specific image.
- **Stickers:** pulled from "Soft iOS Sticker Library" (`https://www.canva.com/design/DAHRyHjQ_Qc/N7esq05WvuB4UV0H2DkaKw/edit`) — soft-outline pastel style (washi tape, squiggle underline, location pin, small circular tab, torn paper). 1-2 per slide max, corner/pocket accents only.
- **Backgrounds:** "AI UGC" folder (`https://www.canva.com/folder/FAHRyAovA_k`), Pack 4 → Set 4 ("Nightstand Edit"), Pack 5 → Set 5 ("Morning Pages").
- **Editability:** every deliverable must stay native Canva — live text layers, replaceable photo frames, separate ungrouped sticker elements. Nothing flattened or rasterized.
