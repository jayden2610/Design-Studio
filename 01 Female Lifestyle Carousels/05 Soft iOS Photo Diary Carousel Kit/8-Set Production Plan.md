# Soft iOS Photo-Diary Carousel Kit — 8-Set Production Plan

## Delivery architecture

- Eight Canva designs, one complete five-page carousel per design (40 pages total).
- Every page: 1080 × 1350 px, editable Canva text above an actual Canva image background.
- Each set follows the same buyer-friendly sequence: cover, moment, editable list, visual recap, close.
- The existing five one-page designs are the covers for sets 01–05. The build adds four pages to each and creates sets 06–08 from the same locked visual system.

## Editable page copy

### 01 · Weekend Notes

1. `WEEKEND NOTES · 01` / `the kind of morning i want to keep` / `coffee, a few pages, and nowhere urgent to be.`
2. `slow moments from lately` / `[one small moment you want to remember]`
3. `my little weekend list` / `01 · [favourite drink]` / `02 · [something i read]` / `03 · [a place i went]`
4. `camera roll evidence` / `[city] · [month] · [year]`
5. `a soft ending to a good weekend` / `what would you keep from yours?`

### 02 · Little Rituals

1. `LITTLE RITUALS · 02` / `small things that made the day softer`
2. `a ritual i come back to` / `[a short sentence about your slow moment]`
3. `today's soft list` / `01 · [ritual]` / `02 · [ritual]` / `03 · [ritual]`
4. `the details i notice when i slow down`
5. `a reminder: ordinary can still feel special` / `save this for your next quiet day`

### 03 · Soft Reset

1. `SOFT RESET · 03` / `a gentle way back to myself`
2. `starting smaller than usual` / `[one doable reset step]`
3. `my reset, lately` / `01 · [make the bed]` / `02 · [make a drink]` / `03 · [put one thing away]`
4. `nothing dramatic — just little care`
5. `you don't have to do everything to begin again` / `what's one thing you can reset today?`

### 04 · Currently Loving

1. `CURRENTLY LOVING · 04` / `the small things in heavy rotation`
2. `one thing i keep reaching for` / `[favourite 01]`
3. `my current five` / `01 · [favourite]` / `02 · [favourite]` / `03 · [favourite]` / `04 · [favourite]` / `05 · [favourite]`
4. `a few more things worth keeping close`
5. `that's the little list for now` / `what's on yours?`

### 05 · Little Life Update

1. `LITTLE LIFE UPDATE · 05` / `a few pieces of lately`
2. `one thing that's felt good` / `[a small update]`
3. `life lately, in three lines` / `01 · [what changed]` / `02 · [what you are learning]` / `03 · [what you are enjoying]`
4. `the ordinary proof that life is moving`
5. `see you in the next little update` / `[month] · [year]`

### 06 · Things That Made Me Happy

1. `THINGS THAT MADE ME HAPPY · 06` / `tiny joys from the week`
2. `this one made me smile` / `[a small happy moment]`
3. `a gentle happiness list` / `01 · [small joy]` / `02 · [small joy]` / `03 · [small joy]`
4. `proof that good things are often quiet`
5. `more of this, please` / `what made you happy lately?`

### 07 · A Day in My Life

1. `A DAY IN MY LIFE · 07` / `nothing fancy, just my little day`
2. `09:00` / `[your morning moment]`
3. `the middle of the day` / `12:30 · [lunch]` / `15:00 · [task or errand]` / `18:00 · [small pause]`
4. `the bits between the big things`
5. `a full day made of little moments` / `see you tomorrow`

### 08 · Monthly Favourites

1. `MONTHLY FAVOURITES · 08` / `five things that stayed with me`
2. `the one i would recommend first` / `[favourite 01]`
3. `this month's list` / `01 · [book / beauty / place]` / `02 · [favourite]` / `03 · [favourite]` / `04 · [favourite]` / `05 · [favourite]`
4. `a few visual notes from the month`
5. `until next month's little list` / `[month] · [year]`

## Build order

1. Add four full-bleed background pages to each of the five existing cover designs, one background image per page from the corresponding pack.
2. Build three new five-page designs from the same native-text system for sets 06–08.
3. Add the copy above as independent text layers; retain simple visual hierarchy and do not flatten text into the image background.
4. Validate page count, background treatment, and legibility before delivery.
