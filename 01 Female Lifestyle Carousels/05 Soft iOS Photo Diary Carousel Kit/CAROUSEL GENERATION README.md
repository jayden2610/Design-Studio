# Soft iOS Photo-Diary Carousel Kit — Generation Guide

This is the production brief for creating the eight Canva carousel sets in the Soft iOS Photo-Diary kit. It translates the Etsy research into a reusable system, so every set feels like one product while still solving a distinct posting job.

## 1. Product Positioning

**Customer:** female lifestyle and personal-brand creators who have a camera roll full of everyday moments but do not want to design a carousel from scratch.

**Core promise:** turn a camera roll into a polished, personal Instagram carousel in about 10 minutes, using Canva Free.

**Not:** a generic iOS UI kit, a giant unstructured sticker vault, or a seamless-only scrapbook bundle.

**Product architecture:**

- Eight editable 4:5 carousel sets, five slides each (40 pages total).
- One sticker-library design with 70 separately selectable, copy-and-paste stickers.
- Canva Free-compatible typography and no Canva Pro dependency.
- Modular slides first; a few optional connected/spread compositions second. A buyer must be able to use one slide, reorder it, or make a whole carousel without breaking the design.

### Face strategy

The templates must work for both visible-face and faceless creators. Use one warm selfie or friends example in product previews to make the kit human, but never make a face structurally required. Every photo placeholder should accept a face, object, or environmental lifestyle image.

## 3. Visual System

### Design principle

**Photo first, iOS second, stickers third.** The photo carries the intimacy. Generic soft iOS-style cards provide context. Stickers add a final lived-in detail. If the interface becomes the hero, the design will read as a generic UI kit rather than a creator’s diary.

### Format and spacing

- Artboard: **1080 × 1350 px (4:5)**.
- Safe margin: 72 px minimum on every edge; 96 px for long title blocks.
- Photo border: 8–16 px warm cream, depending on image size.
- Rounded corners: use 24–36 px for mobile-style cards; do not round every element.
- Keep each slide to 2–5 photos and 2–4 stickers maximum.
- Establish one visual anchor per slide: an oversized image, editorial title, Notes card, or collage block. Never give all elements equal visual weight.

### Palette

Use this as the default system. Individual carousel sets can select one accent, but should not introduce new colours.

| Role | Hex | Use |
| --- | --- | --- |
| Cloud paper | `#F8F5F2` | Main background |
| Warm blush | `#F4D8D5` | Cards, tape, gentle blocks |
| Powder blue | `#DCEAF2` | iOS utility accents |
| Pale lavender | `#E6DDED` | Secondary diary accents |
| Cream | `#FFF9F2` | Photo mats and Notes paper |
| Soft graphite | `#343338` | Main text and thin UI lines |
| Muted cocoa | `#9D6A62` | Optional metadata / outline accent |

Avoid saturated red, bright pure blue, black backgrounds, or multiple checkerboard patterns. Those are common Etsy scrapbook signals but would dilute the more restrained premium position.

### Typography

Use only two type families in a carousel set.

- **Utility family:** DM Sans, Inter, or Manrope. Use for UI labels, dates, metadata, lists and small text.
- **Diary title family:** Playfair Display, Cormorant Garamond, or Libre Baskerville. Use for covers and one short emotional line only.

Rules:

- Sentence case for diary titles; avoid all caps except 8–12 pt metadata.
- Title: 76–122 px depending on length. Utility labels: 20–28 px. Body/list text: 26–34 px.
- Do not use a handwriting font in the core system. A hand-drawn underline/circle sticker supplies the handmade effect without damaging readability.
- Use a single font weight hierarchy: title / regular / small metadata. Avoid bolding every label.

### Image treatment

- Prioritise real camera-roll photos: cafés, food, books, flowers, beauty, desk, travel, friends, outfits, home and small rituals.
- Grade all example photos consistently: slight desaturation (about -5%), soft contrast, warm highlights, no harsh filters.
- Favour daylight, flash-on-digital-camera, or soft indoor window light. Avoid highly commercial studio stock imagery.
- Use 1 large photo plus 1–4 small supporting images. Do not make all images the same size.

## 4. Sticker Usage System

The 70 stickers are a usable asset system, not decoration to cover empty space.

| Sticker group | What it does | Max per slide | Best use |
| --- | --- | ---: | --- |
| iOS content cards | Adds a title, context, list or location | 1 | Notes, search, now-playing, messages, calendar |
| Photo-diary layers | Frames a photo or creates scrapbook depth | 1–2 | Polaroid, film strip, tape, date stamp, postcard |
| Doodle / annotation | Directs attention | 1 | Circle or underline only |
| Lifestyle finishing touches | Reinforces the story | 1 | Matcha, book, lip gloss, bouquet, travel object |
| Original outlined lifestyle objects | Adds an everyday ritual | 1 | Coffee, skincare, desk, movement, home |

### Composition rules

1. Start with photographs and text before adding stickers.
2. Use one iOS card *or* one framed-photo motif as the main graphic device; do not compete them on the same slide.
3. Place a sticker where it supports meaning: a calendar on a monthly recap, a now-playing card on a weekend diary, a Notes card on favourites.
4. Maintain copy-and-paste usability: each sticker remains an independent Canva image layer, never flattened into the page background.
5. Do not use Apple logos, actual Apple app screens, or proprietary app iconography. The visual language remains generic and iOS-inspired.

## 5. Five-Slide Pattern for Every Set

Each set should feel complete while allowing any page to stand alone.

1. **Cover / hook** — large title, one hero photo or photo cluster, date/location metadata, one restrained sticker.
2. **Story / moment** — 1–2 photos plus a short diary sentence, message card, or small iOS utility layer.
3. **List / favourites** — Notes-style list, numbered favourites, mini timeline, or useful reflection. Must be editable text, never image text.
4. **Collage / evidence** — 3–5 photos with one film, Polaroid, tape, or postcard layer.
5. **Close / CTA** — a short closing thought, question, or save/share prompt; include a photo or quiet graphic layer so it does not look like a generic engagement slide.

## 6. Content Copy Rules

The copy must feel specific enough to publish, while staying clearly placeholder-like.

- Use relatable, small-scale details: “a quiet Sunday reset,” “little things from lately,” “my current five,” “the weekend in soft focus.”
- Avoid claims such as “viral,” “high-converting,” or “must-have.” The buyer is buying a posting ritual, not hype.
- Covers should be 3–7 words. Supporting copy should be 8–22 words.
- Every editable field needs a plain-language placeholder, e.g. `[your title]`, `[month]`, `[favourite 01]`, `[one-line thought]`.
- When writing a CTA, use a natural next action: “save this for a slow Sunday,” “what’s been making you happy lately?”, “see you in the next little update.”

## 7. Batch Production Workflow

### A. Lock the system first

1. Create a master 1080 × 1350 Canva file.
2. Add palette swatches, font specimens and two photo frame styles.
3. Build reusable components: cover title block, date/location row, Notes card, image frame, collage grid, close-slide CTA.
4. Add the 70-sticker library as independent, selectable image layers in a separate buyer-facing page/design.

### B. Build the first set as the control sample

Use **Weekend Photo Diary** or **Little Life Update** first. They demonstrate both photo-first storytelling and the iOS/sticker system without requiring product-specific imagery.

For each slide, create:

- a styled example version using supplied demonstration photography;
- a buyer-editable version with photo frames and clear text placeholders;
- only Free Canva assets and fonts.

Validate it in a duplicate Canva account before using it as the batch master.

### C. Batch the remaining seven sets

1. Duplicate the approved five-page master.
2. Swap only the content structure needed for the use case; retain grid, spacing, palette and type hierarchy.
3. Select intentional stickers based on the usage table above.
4. Check every slide at mobile preview size, then export a PNG proof.
5. Build a styled cover thumbnail for every carousel set; these become Etsy gallery assets as well.

### D. Final buyer delivery

- One duplicable master Canva template link.
- Sticker-library pages containing all 70 individual, copy/paste image layers.
- Quick-start PDF: duplicate, replace photos/text, copy stickers, export in 4:5, permitted commercial use for finished content only.
- Licence: no resale, redistribution, sublicensing, template sharing or competing asset packs.

## 8. Required Inputs for a Batch

### Already available

- **70 transparent stickers:** 30 original lifestyle stickers plus 40 soft iOS/photo-diary additions.
- **Direction:** positioning, use cases, visual system and Etsy listing strategy.
- **Font source:** Google Fonts can supply the system fonts.

| Reusable Canva components | **Yes** | Needed for consistent and efficient eight-set production | Title block, metadata line, Notes/list card, collage, CTA |
| Copy deck | **Yes** | Avoids writing placeholder copy ad hoc during design | 8 set scripts × 5 slides |
| Thumbnail/mockup asset plan | **Yes** | Required to sell the kit, separate from the template itself | Phone mockup, before/after, use-case montage, sticker preview |
| Quick-start and licence copy | **Yes** | Prevents support questions and sets resale terms | 1–2 pages plus template link |

### Background answer

Yes: you need backgrounds, but **not 40 separate illustrated backgrounds**. Build four reusable base backgrounds in the locked palette:

1. Cloud paper — `#F8F5F2`, clean default.
2. Warm blush wash — `#F4D8D5`, for reset and self-care slides.
3. Powder-blue utility wash — `#DCEAF2`, for iOS / monthly utility slides.
4. Pale-lavender diary wash — `#E6DDED`, for closing or reflective slides.

Add one very subtle grain or paper texture only if it stays lightweight and Canva Free-compatible. Backgrounds should support photos, not become a competing visual asset.

### Image answer

Yes: images are the biggest missing production input. Stickers and fonts alone cannot demonstrate a photo-diary product. You have three clean options:

1. **Best:** use your own camera-roll-style photography or commission/obtain creator-approved imagery.
2. **Practical:** source licensed free stock from Pexels/Unsplash, record the source, then apply one consistent colour grade. Use examples that feel personal rather than commercial.
3. **Flexible:** generate original lifestyle images, but keep the prompt/style consistent and ensure your product licence permits their commercial use.

Do not embed unlicensed images for buyers to reuse. If the examples are only for listing previews, say so; in the editable template, use easy-to-replace photo frames or clearly licensed included images.

## 9. Preflight Checklist

Before publishing the Canva link or Etsy listing, verify:

- [ ] Every page is 1080 × 1350 and legible in mobile preview.
- [ ] Every text field is editable.
- [ ] Every photo is in an easy-to-replace frame, or clearly labelled as an example image.
- [ ] All 70 stickers are separate, selectable Canva layers with no missing assets.
- [ ] No Canva Pro font, stock element or background is required.
- [ ] Each five-slide set has a cover, story, list, collage and close/CTA.
- [ ] The kit supports both face-visible and faceless content.
- [ ] One buyer-copy test has been duplicated into a fresh Canva account.
- [ ] One complete five-slide carousel has been exported as PNGs and checked on a mobile device.
- [ ] Etsy assets include hero, use cases, inventory, before/after, edit demo, licence slide and video.

## 10. What Makes This Different

Competitors often compete on template count, generic “viral” language, or a pile of scrapbook stickers. This kit wins when it makes the transformation tangible:

> **Camera roll → polished little-life story, in 10 minutes.**

The defensible difference is a curated photo-first system with a genuinely usable 70-element copy/paste library, Free Canva compatibility, modular slides, and real lifestyle posting use cases.
