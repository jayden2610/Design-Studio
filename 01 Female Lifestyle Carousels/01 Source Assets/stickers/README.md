# Sticker Library and Agent Selection Rules

This file is the source of truth for choosing stickers in the Female Lifestyle Carousel workspace.

## Non-negotiable selection rule

Choose the carousel system before choosing a sticker. Do not mix sticker languages simply because an asset is available.

| Carousel system | Allowed sticker language | Density |
| --- | --- | --- |
| Reading Nook Editorial | Editorial fasteners and hand-drawn marks: tape, paperclip, underline, circle, date stamp, restrained torn paper | 0-2 per slide |
| Playful Scrapbook Social | Hearts, stars, flowers, reactions, labels, tape, Polaroids, doodles, bows, frames | 2-5 pieces in one deliberate cluster |
| Soft iOS Photo Diary | Lifestyle objects, generic mobile UI, photo frames, reactions, utility cards | 1 dominant asset plus 0-2 supporting accents |

### Placement rules

1. A sticker must attach, frame, underline, circle, label, or react to something. Never float an unrelated object in empty space.
2. Use varied rotations, normally between -12 and +12 degrees. Do not leave every piece straight.
3. Keep faces, hands, food, books, screens, and other story anchors unobstructed.
4. Match the palette and visual weight of the active system.
5. Inspect the whole carousel after placement; repeated clusters should feel related without being identical.
6. For Reading Nook, prefer one purposeful mark over a decorative object.
7. For Playful Scrapbook, build a cluster around one focal point rather than scattering decorations into every corner.

## Agent decision sequence

1. Read the active carousel system from the brief or `content.json`.
2. Read the corresponding allowed sticker language at the top of this file.
3. Choose a sticker for a functional reason: attach, frame, annotate, label, or react.
4. Use the Canva asset ID when editing Canva; use the local PNG/SVG when rendering HTML.
5. Apply a purposeful rotation and overlap.
6. Preview all slides together and remove any sticker that competes with the headline, face, or primary story object.
7. Never select a large lifestyle object for Reading Nook unless the brief explicitly changes the visual system.
