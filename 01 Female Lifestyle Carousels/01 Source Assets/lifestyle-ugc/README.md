# AI UGC / Lifestyle Source Folder

These images are shared source assets. They can be used by both active visual systems, but each carousel must choose one contract before layout begins.

## Use with Playful Scrapbook Social

| Asset group | Best use |
| --- | --- |
| `01–05 pack1` | Paper Note Over Photo, Camera-Dump Collage |
| `06–09 pack2` | Labelled Photo Grid, Stickered Hero Cover |
| `10–14 pack3` | Paper Note Over Photo, soft reset / self-care posts |
| `15–18 pack4` | Labelled Photo Grid, current favourites, planner close |
| `19–22 pack5` | Camera-Dump Collage, food and morning-routine posts |
| `23–27 pack6` | Stickered Hero Cover, places and weekend recap |
| `28-pack1-filler-windowlight` | Quiet closing slide or background detail |
| `anchor*.png` | Optional identity, kitchen, or lived-in context layer |

Use the outlined lifestyle stickers in `..\stickers` as independent finishing layers. Pick 2–5 per slide and keep one dominant photo, headline, or card.

## Use with Reading Nook Editorial

The same images can support the quieter system. When using that contract, remove the scrapbook layering, reduce the sticker count, use more generous margins, and follow the contract and patterns in `..\..\00 Visual System\VISUAL-CONTRACT.md` and `..\..\00 Visual System\LAYOUT-PATTERNS.md`.

For the playful system, follow `..\..\00 Visual System\PLAYFUL-SCRAPBOOK-SOCIAL-CONTRACT.md` and `..\..\00 Visual System\PLAYFUL-SCRAPBOOK-SOCIAL-PATTERNS.md`.

Do not combine the two pattern sets on one carousel.
