## Slide 1 — COVER

**Photo:** `anchor-user-identity.png` → full-bleed (stretch to fill 1080×1350, centered)

### Rounded Block
1. Elements → Shapes → Search "rounded rectangle" → pick one with soft corners
2. Size: ~780w × 320h
3. Position: center (x=540, y=620)
4. Color: `#F8C8DC` (Blush pink)
5. Transparency: 45% (so collage shows through)

### Typography

| Element | Text | Font | Size | Color | Position |
|---------|------|------|------|-------|----------|
| Label | `A PHOTO JOURNAL` | Montserrat SemiBold | 13pt | `#FFF9F0` | Top-left corner (~x=100, y=90), letter-spacing 200 |
| Headline L1 | `one day` | Poppins Bold | 72pt | `#FFF9F0` | Centered on block, y≈575 |
| Headline L2 | `in my life` | Poppins Bold | 72pt | `#FFF9F0` | Below L1, y≈665, tight line height (0.9) |
| Accent | `with me` | Playlist Script | 32pt | `#F8C8DC` | Centered below block, y≈800 |

### Decor
- Search "star sparkle" → add 3–5 stars, recolor warm yellow `#F5E6C8`, scatter around block with varied rotation
- Search "heart" → add 1 tiny heart near the label, colored `#F8C8DC` at 40% opacity

## Slide 5 — CTA

**Photo:** `24-pack6-establishing-park.png` → full-bleed

### Dim Overlay
1. Full-canvas rectangle 1080×1350
2. Fill: `#3A2E2A`, Transparency: 55% (45% opacity)
3. This dims the golden hour photo so the white CTA block commands attention

### White CTA Block
1. Rounded rectangle ~700w × 300h
2. Position: center (x=540, y=675)
3. Color: `#FFF9F0` (Cream), 100% opacity (solid)
4. Corner rounding: ~30px
5. Optional: Effects → Shadow → Soft, color `#D8C8E8`, blur ~20

### Typography

| Element | Text | Font | Size | Color | Position |
|---------|------|------|------|-------|----------|
| Headline | `save & follow` | Poppins Bold | 52pt | `#F8C8DC` | Centered in block, y≈630 |
| Accent | `[ for more photo diaries ]` | Montserrat Light | 16pt | `#B8C4A8` | Centered below, y≈710 |

**Note:** If using Playlist Script at 20pt for the accent is readable, use it. Otherwise Montserrat Light 16pt is the safe fallback.

### Decor
- 3–4 blush-colored stars (`#F8C8DC` at 70% opacity) around the white block
- 1 tiny lavender heart near the headline

## Final Checks

- [ ] Every slide has 2–3 pastel colors + cream max
- [ ] All headlines are Poppins Bold, 52–72pt
- [ ] All accents are Playlist Script (or Montserrat Light on CTA), 16–32pt
- [ ] Every slide has 2–5 star sparkles (yellow/golden/blush)
- [ ] CTA uses solid white block (not transparent) with bracket caption
- [ ] Photos are full-bleed, not stretched disproportionately
- [ ] Group elements per slide for easy adjustment (Ctrl+G)
