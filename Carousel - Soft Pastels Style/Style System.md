# Style System — Soft Pastels

*Reusable system prompt / knowledge base for the agent. Defines the aesthetic for every carousel in this folder. Lock the vibe once; apply to every slide.*

---

## 1. Palette
Soft pastels. Limit to **2–3 colors + white space per slide.**

- Blush pink — `#F8C8DC` (or similar)
- Cream / off-white — `#FFF9F0`
- Muted sage — `#B8C4A8` (or similar)
- Soft lavender — `#D8C8E8` (or similar)
- Warm beige — `#E8DCC8` (or similar)

## 2. Typography Hierarchy

**Primary — Big emotional phrases**
- Bold or medium-weight modern sans (Poppins, Montserrat, Quicksand, or similar rounded geometric) — OR soft serif for emotional headlines.
- Large, high contrast.
- Keep phrases short: **1–6 words max per headline. Never long paragraphs.**

**Accent / Secondary — small supporting lines**
- Light handwritten / script (Playlist Script, Allura, Brittany Signature style) — or thin elegant.
- Small, decorative, for captions / sub-lines.

## 3. Placement & Treatment
- Treat text as a **design object** — overlaid on photos with slight transparency, or on solid pastel blocks.
- Frame with stickers / stars / hearts.
- Diagonal or stacked text; generous breathing room, but collage density.
- Mix centered big type with corner accents.

## 4. Overall Vibe
Cozy, feminine, Pinterest soft-girl / "in my _____ era", lifestyle photo dump, optimistic, low-clutter but layered.

## 5. Constraints
- **Always leave space for the user's real photos.**
- Output must be **Canva-actionable**: exact text strings, suggested Canva font names, approximate size/weight, position notes, color hex when possible.
- Prefer generating **text + layout notes** over baking text into AI images.
