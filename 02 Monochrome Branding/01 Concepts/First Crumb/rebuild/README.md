# Rebuild protocol

This folder contains standalone logo SVGs. For each new mark, preserve one sensory promise, one ritual gesture, and one silhouette cue. Remove props, texture, and scene explanation before adding detail.

Validation checklist: parse SVG as XML; inspect positive and reversed contrast; test symbol-only and lockup; reduce mentally to 24 px digital / 20 mm print; verify every review HTML path exists; score with the monochrome reviewer before selecting a top direction.
