# Mindset Daily — Typography logos

Three pure-typography logo directions for a white-background TikTok profile image. Each SVG and PNG is **1080 × 1080 px** and keeps the full name in the central profile-safe area.

## Recommendation

Choose **01 — Bold Stack** for TikTok. It makes both words as large as possible, so it is the best full-name read at small sizes.

Use **02 — Editorial Contrast** when the channel is thoughtful, reflective, or more premium. Use **03 — Calm Cadence** for a softer, less assertive voice.

The vector text remains editable. PNG exports preserve the exact appearance for upload.
