# Production Roadmap

## Recommended first release

**Product:** Female Lifestyle Storytelling Carousel Pack — MVP

**Buyer:** female lifestyle creators making content about routines, self-care, relationships, soft productivity, home, fashion, and personal growth.

**Promise:** a polished carousel that feels like a real documented moment, not a generic stock template.

**MVP scope:** 15 editable 4:5 Canva carousels, each with 5–8 slides, plus 15 covers, 10 Story adaptations, 20 hooks, and a concise usage guide.

> [!important] Product decision
> Start with one visual direction: **warm, candid, editorial real-life**. Avoid mixing coquette, scrapbook, luxury, and nature-poster aesthetics inside the first paid pack. Variety should come from the story and layout, not a changing brand identity.

## What to create

### 1. Brand system — create before designing templates

- [ ] A one-page art direction: mood, audience, anti-style, and three reference images.
- [ ] Palette: 5–6 colours with accessibility-safe text pairings.
- [ ] Type system: one display serif, one supporting sans, one optional handwritten accent; document sizes for cover, headline, body, labels, and CTA.
- [ ] Layout system: safe margins, grid, slide sequence, caption length, and image-to-text ratio.
- [ ] AI UGC character policy: faceless, consistent character, or mixed models; use only commercial-safe assets and keep a source log.

### 2. The 15-template MVP

Create three repeats of each storytelling job below:

- [ ] Personal reflection / “I learned this when…”
- [ ] Soft productivity / routine
- [ ] Self-care / reset
- [ ] Mindset shift
- [ ] Everyday documented moment

For every template, create:

- [ ] Cover with an editable hook.
- [ ] 5–8-slide copy and image layout.
- [ ] Final soft CTA / save-share prompt.
- [ ] Canva link, a thumbnail, and a test export at 1080 × 1350.

### 3. Sales package

- [ ] 15 Canva template links organized in one delivery PDF.
- [ ] Usage guide, licence terms, and a “duplicate before editing” instruction.
- [ ] 20 proven hooks and 10 caption prompts as a bonus.
- [ ] 5–7 phone mockups and 8 Etsy listing images.
- [ ] Etsy listing copy, tags, and a Gumroad mirror.

## Next steps

1. **Today:** choose and document the single visual direction and type pair; create the first 3 carousels from it.
2. **This week:** generate a 25–30-image AI UGC library, then build and QA all 15 templates.
3. **Next week:** produce mockups, delivery PDF, licence, Etsy listing, and Gumroad product.
4. **After 10–20 sales or useful buyer feedback:** expand to 30–60 templates, add a Story pack, and test a clearly separated PLR edition.

## Monochrome collection — parallel, not launch-blocking

Use this line to build a strong portfolio and validate offers with a few real brands.

- [ ] Select the top three existing directions and name them.
- [ ] Turn each direction into a mini identity kit: logo, icon/illustration language, typography, packaging/menu/social mockups, and one-page rationale.
- [ ] Create two target briefs: one personal-brand service and one neighbourhood F&B concept.
- [ ] Package it as a separate service or later product collection; keep it visually and commercially separate from Female Lifestyle Carousels.

## Quality gate

- [ ] A cover communicates its topic in under two seconds on a phone.
- [ ] Every carousel tells one emotional story; no filler slides.
- [ ] Type has clear hierarchy and remains editable in Canva.
- [ ] Image rights, prompts, and source files are recorded.
- [ ] All downloadable links, licence wording, and mockup claims have been tested.
